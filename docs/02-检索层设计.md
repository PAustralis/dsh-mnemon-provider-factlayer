# 第二层 · 检索层设计（v5，两轮评审后的定稿候选）

> 修订记录：
> - v1→v2：按实测重划路线 → v3：吸收第一轮评审 6 处 → v4：吸收第二轮评审 9 处
> - v5：吸收第二轮复核的 3 处阻塞（B1 排除与替换的矛盾、B2 环处理、B3 显式 seq）+ 9 条细则（N1–N9）
>
> **编号对照**：本文 R2 = 二元组（实测报告记作 R3），R1 = 向量。

## 0. 一句话

**事实层不动；检索层只保留有证据的路线。被作废的记录不是"看不见"，而是"被它的存活纠正者顶替"；排除只发生在最后一道出口。出厂只开一条路。**

## 1. 实测基线

语料 119 条 / 题库 40 题；随机基线 R@6 = 0.0505。

| 路 | R@6 | R@10 | MRR | 覆盖@50 | 空结果 |
|---|---|---|---|---|---|
| R2 二元组 | **0.4875** | 0.5000 | 0.6269 | 0.5000 | 2/40 |
| R1 向量（TF-IDF 替身） | 0.4583 | **0.5333** | 0.6051 | **0.6667** | 0 |
| trigram（不实现） | 0.1750 | 0.1750 | 0.3083 | 0.1750 | 24/40 |
| 最近 50（不作路） | 0.0667 | 0.1062 | 0.0974 | 0.4479 | 0 |
| unicode61（已废） | 0.0000 | 0 | 0 | 0 | 39/40 |

结论：31 种融合无一超过最好单路；RRF 收益 CI 跨 0；最近路显著有害；MMR 增益 0；唯一正向是 MRR +0.008。

**局限**：向量路是 TF-IDF 替身；119 条规模小（80 个候选位，容差 0.01 ≈ "一条都不能翻"）；golden 是相关记录而非答案集。

## 3. 排序与单调序（B3）

### 3.1 显式 seq

- `memories` 增加 **`seq INTEGER PRIMARY KEY AUTOINCREMENT`**（`id TEXT` 保留为对外稳定标识，改 `UNIQUE NOT NULL`）。理由：隐式 `rowid` 会因 `VACUUM` 重编号、删除最大行后复用，而我们的备份正是 `VACUUM INTO`。
- 迁移：项目尚无生产数据，建表时直接采用新结构并写 `migrate_memories_seq()`（旧库检测到无 seq 列则重建并回填）；README 注明。
- tie-break：**seq DESC**（新者优先）。不采信客户端时钟。
- `supersedes` 最新边判定：**`ORDER BY id DESC` 单一主序**（id 为 AUTOINCREMENT），不再依赖 `recorded_at`——时钟回拨会让"最新边"选错。

## 4. 作废与纠正（B1 + B2 + N1 + N2）

### 4.1 每查询一份快照

同一只读事务内算：`voided`（per-pair 最新边为 supersede 的 to_id 集合）与 `live_head`（被作废项的存活纠正者，递归 CTE，`UNION` 去重自带环保护）。

快照**只服务"替换"**，不用于在各路检索阶段排除记录——这是 B1 的修正。

### 4.2 路内替换（RRF 之前）

```
每路取原始 top-K（K=50，允许包含 voided）
  → 对每个命中 A ∈ voided：用 live_head(A) 占据 A 在该路的原始名次，A 移出该路列表
  → 路内去重：同 id 取最佳（最小）名次；每路每 id 至多一票
  → 按（名次 asc, seq desc）确定性排序后截断到 50
  → 进 RRF
```

- **跨路各得一票是正当多路证据**：同一纠正者被两路命中就两票，不是重复计票；同路内绝不重复计票（N1）。
- 被作废项只是"位置提供者"，不进 RRF 列表。
- 多个存活纠正者：**并列继承 A 的同一名次**，路内去重后各得一票；输出按 seq 新→旧排列并标「取代 id=A」。
- **纠正如因取代而入选**（文本不含查询词）也打标签，避免读者以为它本身匹配（N2）。
- FINAL_K=6 是替换后的 6；纠正者占名额，不额外加条。

### 4.3 环（B2）

- **写入时拒绝成环**：`supersedes` 新边若使 (from_id→to_id) 图产生环（含自环），在同一写事务内检测并返回 409「该裁决会形成循环，已拒绝」，原始错误只进日志。单写者保证检测可靠。
- **读路径的防御**（历史数据或迁移残留）：检出环时——
  - 环整体在 RRF 里**只算一票**（按环内最佳名次），避免 50 个成员占满该路 top-50；
  - 输出最多展示 **3 个**成员（按 seq 最新），其余只列 id 与数量；
  - 全部成员标记「循环裁决」；
  - 12 条输出上限照常生效。
- 环成员与"链超长已截断"节点**豁免**于出口断言（它们不在 voided 语义内，而是防御路径产物）。
- 链：安全阀 20 跳，触顶输出已到达节点并标注「链超长已截断」，不丢弃数据。

### 4.4 出口断言与豁免

最终输出若含 voided 成员且不属于下列豁免：环成员（标注）、链截断节点（标注）、`include_superseded=true` 的显式请求 → 丢弃、计数、打 ERROR、测试失败。

## 5. 二元组索引（N5 + N6 + N8）

### 5.1 生成规则（索引侧与查询侧共用同一函数）

1. `content` → NFKC → 码点切段：`CJK 连续段` / `Latin+数字连续段` / `其他（标点空白）`。标点空白断开 CJK 段，不跨段产双字。**CJK 范围写明**（含汉字，假名/谚文是否纳入按实现注明）。
2. `bi` 列：CJK 段内按码点产双字；Latin/数字段整段小写作为一个 token。`uni` 列：CJK 段内产单字；Latin 段同 bi。
3. 两列分别建 FTS5（`unicode61`），**不混列**（混排扭曲 BM25 长度与 IDF、破坏短语邻接）。
4. 函数必须是**全函数**：非法代理对、超长文本不抛异常（因"派生失败=写入失败"）；`content` 设长度上限（超限在写入层显式拒绝）。

### 5.2 查询构造

- **主路径（bi）**：逐字复刻 `research/recall` 基线：分段 → 每段产双字 → 转义 → `OR` 连接。**Golden fixture 机制保证复刻**（N6）：
  - `research/recall` 一次性生成 fixture（基线查询串 + 该题预期 top-6 + sha256 + 基线 commit id），提交进产品仓库；
  - 产品测试读 fixture，用**产品自己的构造器**重算，断言 token 序列与最终查询串**逐字节相等**；运行时不依赖 research 代码；
  - 转义若改变字节：分别存档"转义前 token 序列"与"转义后最终串"两份黄金文件，并对基线语料断言转义恒等。
- **兜底（uni）**：bi 无命中时用单字 OR，结果标 `weak:true`，**不参与 RRF**（单字噪声大，融合会靠命中数压过 bi）。
- token 转义双引号并禁用 NEAR/AND/NOT/`*`；查询 token 上限 200，超出截断并计数。

### 5.3 写入即索引

ngram 派生与事实写入**同一事务**；派生失败 = 写入失败（显式报错）。不许"写进去了搜不到"。

## 6. 融合与输出

```
快照(voided, live_head)
  → 每路：top-50（含 voided）→ 路内替换 → 去重 → 确定性排序 → 截断
  → RRF(k=60)：Σ 1/(60+rank)
  → 同分 seq 大者优先
  → 取 6 条
  → [会话展开：默认关；开启时过替换语义、不占名额、继承名次、确定性合并]
  → 输出上限 12 条 / 12000 字符（含本体；超限列出被丢弃 id 与数量）
  → 截断自报（>1200 字符标「[已截断，原文 N 字，id=…]」）
  → 出口断言（豁免见 4.4）
```

### 6.1 无命中与降级

- **NO_MATCH**：显式状态 + 路状态摘要（参与路、降级路、查询 token 数），绝不"多路皆空却返回空列表"。
- **弱匹配**：uni 兜底与低分结果标 `weak:true`。
- **被纠正记录计数**：「另有 N 条与你相关、已被纠正，未显示」——**N 只计"被替换掉而未出现在输出"的记录**，不重复计已展示的纠正者；`include_superseded=true` 可查看历史说法。
- **最近记录**：无命中时可选独立分区「最近记录（与查询无关）」，明确标注未经相关性判断，不混入主结果。
- **展开/截断**：列出被丢弃 id 与数量。

## 7. 降级、重建、告警

- **质量决策离线做**（发布时用冻结语料跑基准 → 写进默认配置）；运行时只按**故障**降级：超时（R1 单次 3 秒）、报错、维度不符、空结果率异常；连续 3 次失败熔断 5 分钟。
- **金丝雀**（N3）：抽存活记录，子串取自单个 CJK 连续段内、≥6 字（Latin 取 2 个罕见词），不跨标点；预期用 `instr` 精确匹配；只对 bigram 路严格断言（预期 ≤6 条时全入 top-6，否则至少一条）；固定种子；N=20，连续两次运行失败率 ≥20% 才告警；写入后 / 重建后 / 每日触发，不放每次查询；标 `canary` 不计统计；失败记录 id。
- **重建**（N7）：整个重建放进**一个写事务**（数据量小），防止影子表构建期间的新写入丢失；或影子表 + 切换前补齐。`/admin/rebuild` 绑回环或要求 `ADMIN_TOKEN`。
- **模型变更**（N4）：按行存 `model_id+dim`；无对应行的记录不被 R1 覆盖，R2 照常；模型变更→后台重算（断点续跑、限速、预估总量），超成本上限暂停并告警，**人话措辞**：「向量重建已暂停：已完成 1200/1900 条，已花 $0.50（上限）。回复"继续"可追加预算。」同一告警每会话只出现一次，`/health` 保留完整版。
- **告警必须到达读者**：provider 返回内容里带一行「⚠ 向量路不可用，本次仅文字匹配」。

## 8. 验收标准

1. **基线精确再现**：产品构造器对 fixture 的所有查询串逐字节相等；R@6 = 0.4875（容差 ≤0.01，等于"一条都不能翻"）。确认 tie-break 改 seq 不翻转基线结果；若翻转，查明原因而不是放宽容差。
2. **uni 兜底变体**：单独跑基准，≥0.4875 才允许进主流程为"fallback"；否则仅作开关且默认关。
3. **R1 开关门槛**：重测后 R@6 或 MRR 的提升必须超过样本误差（80 个候选位 → 明确写死门槛，如 R@6 +0.05 且 bootstrap 95% CI 不含 0）。
4. **作废一致性**：性质测试——对每个启用路，输出 ∩ voided ⊆ 豁免集；revoke 恢复可检索；同毫秒 revoke→supersede 以 id 有序。
5. **路内替换**：A 被作废且命中 → 输出含 live_head，占 A 名次、不超额；A 被两路命中 → 纠正者两票；同路不重复计票；多纠正者并列；"因取代入选"标签存在。
6. **环**：写入成环被 409 拒绝（含自环）；历史环数据读出时只算一票、最多展示 3 个、其余列 id 与数量、标注存在；断言豁免生效。
7. **seq**：`VACUUM INTO` 后 seq 不变；tie-break 可复现；迁移函数对旧库正确回填。
8. **无命中语义**：全路空 → NO_MATCH + 路状态；被隐藏匹配 → N 计数正确、`include_superseded` 可用。
9. **中文查询**：1 字、2 字、标点、数字、Latin 混合；FTS5 语法字符（`"`、`*`、`NEAR`、`AND`、`NOT`）不报错不改义；超长查询截断并计数。
10. **写入即索引**：写入成功后立即可被 bi 检索。
11. **重建**：重建过程中查询始终看到完整旧或新索引；重建期间的新写入不丢。
12. **金丝雀**：抽 20 条子串全部命中；人为破坏索引后金丝雀失败并告警/降级。

## 9. 推迟项（条件满足再加回）

- R1 向量：真实 embedding 重测，按 §8.3 门槛决定默认开关。
- R4 图邻居：出现"实体相关但文字不同"的真实召回失败案例再评估。
- MMR：真实 embedding 重测有增益再加。
- 会话展开 ±2：先 ±1 且默认关，基准证明不降低再开。
- 繁简转换：影子列同时索引简转繁 bi；出现繁体语料再上。

## 11. 明确不做

ANN 索引、FalkorDB 承接全文/向量、Graphiti 的 k=1 RRF/一次性 MMR、RRF 加权、学习排序、cross-encoder 重排、分词扩展 `simple`、写入时 LLM 判断、冲突检测、软删除、运行时质量自动降级、把"拒绝检索"作为模型不匹配的响应。

## 12. 风险

1. 规模外推：融合无增益结论来自 119 条；数千条必须重测（发布时离线）。
2. 单路出厂：默认只有 bigram，同义改写查不到——配置 R1 并重测是必要动作；`NO_MATCH` 与覆盖率日志让它可见。
3. 子串极限：bigram 对同义改写无效。
4. golden 口径：标准集是相关上下文；端到端评测要换口径。
5. 语料外发：启用 R1 API 形态会把原文发给第三方 embedding 服务；local-onnx 可避免但需 90MB 冷启动。README 必须写明。
6. 环：写入时拒绝后，真实使用中会以 409 形式暴露给用户；UI 文案需解释"这两条不能互相作废"。
7. 繁简：不转换 = 静默 0 命中，用 /health 繁体字符占比可观测替代。
